# Cisco Networking Basics: Kumpulan Berkas Packet Tracer

Repositori ini berisi kumpulan berkas aktivitas Cisco Packet Tracer dari pembelajaran dasar jaringan komputer (networking) Cisco NetAcad. Isinya adalah berkas latihan (`.pka` dan `.pksz`) dari berbagai modul, bukan aplikasi yang dijalankan dengan kode.

## Isi Repositori

Berkas aktivitas yang tersedia antara lain:

| Berkas | Topik |
| ------ | ----- |
| `1.1.6-packet-tracer-tutored-activitys-logical-and-physical-mode-exploration.pksz` | Eksplorasi mode logical dan physical |
| `2.1.1_packet_tracer_create_a_simple_network.pka` | Membuat jaringan sederhana |
| `8.1.3-packet-tracer-connect-to-a-web-server.pka` | Menghubungkan ke web server |
| `10.2.3-packet-tracer---examine-nat-on-a-wireless-router.pka` | Memeriksa NAT pada wireless router |
| `13.1.3-packet-tracer-identify-mac-and-ip-addresses.pka` | Mengidentifikasi alamat MAC dan IP |
| `14.3.3-packet-tracer-observe-traffic-flow-in-a-routed-network.pka` | Mengamati aliran trafik pada jaringan routed |
| `14.3.4-packet-tracer-create-lan.pka` | Membuat LAN |
| `16.1.5-packet-tracer---the-client-interaction.pka` | Interaksi client |
| `16.4.3-packet-tracer---observe-web-request.pka` | Mengamati permintaan web |
| `16.5.3-packet-tracer---use-ftp-services.pka` | Menggunakan layanan FTP |
| `17.1.3-packet-tracer---use-the-ipconfig-command.pka` | Perintah ipconfig |
| `17.1.6-packet-tracer---use-the-ping-command.pka` | Perintah ping |
| `i287364v1n2_NetEss_1.0_Ch8_PTMO2.pka` dan `i408837v1n1_Packet_Tracer_Quiz.pka` | Aktivitas dan kuis Networking Essentials |
| `T-GCCF1-B-m3-l19-file-en-32.pdf.en` | Berkas materi pendukung (PDF) |

Topik yang dilatih mencakup konsep dasar jaringan, seperti pengalamatan IP dan MAC, NAT, pembuatan LAN, trafik pada jaringan routed, layanan web dan FTP, serta perintah ipconfig dan ping.

## Cara Menggunakan

1. Instal Cisco Packet Tracer (tersedia melalui Cisco NetAcad / Skills for All).
2. Clone repositori ini:

   ```bash
   git clone https://github.com/hafizaryan/cisco-networking-basics.git
   ```

3. Buka berkas `.pka` atau `.pksz` yang diinginkan melalui Packet Tracer (File, Open), lalu ikuti instruksi aktivitas di dalam berkas tersebut.
